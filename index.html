Cópias de segurança do Meu Studio no Google Drive

O Meu Studio Backup é uma integração de uso restrito, criada para apoiar a proteção e a recuperação dos dados operacionais do sistema Meu Studio.

1. Preparação

Uma rotina autorizada prepara cópias de segurança do banco de dados e de arquivos do sistema.

2. Armazenamento

Os arquivos de backup são enviados para uma pasta definida na conta Google Drive expressamente autorizada pelo responsável.

3. Verificação

O processo prevê a conferência da integridade dos arquivos enviados, para detectar falhas de transferência.

Finalidade e acesso

Esta página é apenas informativa. Ela não disponibiliza arquivos, não oferece login para alunos e não permite acessar o banco de dados ou os backups do Meu Studio.

A conexão com o Google Drive exige autorização expressa da conta Google utilizada. Embora a permissão técnica solicitada possa abranger os arquivos do Drive, o uso previsto da integração se limita à manutenção dos backups na pasta designada.

Privacidade: saiba como a integração solicita permissões e trata os dados na Política de Privacidade do Meu Studio Backup.

Contato

Para dúvidas gerais sobre esta integração, o responsável pode ser contatado pelo canal público de suporte no GitHub. Não publique dados pessoais, senhas, tokens ou informações de alunos nesse canal.
